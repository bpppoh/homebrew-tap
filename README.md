# bpppoh Homebrew Tap

Official Homebrew formulae for tools by [@bpppoh](https://github.com/bpppoh).

## Installation

```sh
brew install bpppoh/tap/img-tui
```

Or tap first:

```sh
brew tap bpppoh/tap
brew install img-tui
```

## Available Formulae

- **[`img-tui`](https://github.com/bpppoh/img-tui)** — Offline, keyboard-first terminal image compressor inspired by [`ytd-tui`](https://github.com/sebidc/ytd-tui) and iLoveIMG.
